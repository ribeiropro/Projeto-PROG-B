#  🏋️ ORBE - Organização, Bem-estar, Evolução 

O ORBE é uma aplicação voltada para o gerenciamento e acompanhamento de treinos, criada para ajudar o usuário a organizar seus exercícios, registrar seu desempenho e acompanhar sua evolução ao longo do tempo. A aplicação permite criar fichas de treino personalizadas, registrar a execução dos exercícios e consultar o histórico de desempenho.

## Funcionalidades:

### Criar fichas de treino
- Definindo nome do treino, exercícios, séries, repetições, carga, tempo de descanso, sendo possível criar diferentes fichas, como Treino A, B, C, ou nomes personalizados.

### Registro do treino
- Durante a realização do treino, o usuário poderá registrar o que foi executado em cada exercício. 

- Ex: 
Supino Reto
1ª série: 10 repetições — 20 kg
2ª série: 10 repetições — 22 kg
3ª série: 8 repetições — 22 kg

### Tempo de descanso

- A aplicação contará com um cronômetro para auxiliar o usuário durante os períodos de descanso entre as séries. O tempo poderá ser definido de acordo com cada exercício, adicionado nas fichas ou iniciado manualmente durante o treino.

### Histórico e evolução 

- Ao criar uma ficha e adicionar os exercícios, o usuário poderá salvar o exercício e posteriormente consultar seus treinos anteriores e acompanhar seu desempenho ao longo do tempo.
O sistema apresentará informações como cargas utilizadas anteriormente, maior carga registrada e histórico de exercícios.

### Hidratação

- O ORBE também contará com um sistema para acompanhamento da hidratação.

- Definir uma meta diária de água
- Registrar a quantidade consumida
- Receber lembretes para beber água
- Visualizar o progresso da meta diária.
